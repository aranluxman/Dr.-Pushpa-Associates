# Dr. Pushpa & Associates — Website

Single-page website for **Dr. Pushpa & Associates**, a family dental practice at
7595 Markham Road, Unit 4, Markham, ON L3S 0B6 · (905) 201-8900.

- Pure static site: one self-contained `index.html` (Tailwind CSS via CDN, Google Fonts, vanilla JS).
- No build step. Deploy the repo root as-is to Cloudflare Pages, Netlify, or any static host.

## Deploy to Cloudflare Pages
1. Cloudflare dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. Pick this repo, branch `main`.
3. Framework preset: **None** · Build command: *(leave empty)* · Output directory: `/`.
